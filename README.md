# DAW-JuanJose

Registro de mi progreso en el CFGS Desarrollo de Aplicaciones Web (DAW).
Empecé desde cero en informática, así que este repositorio recoge lo que voy practicando y aprendiendo.

Lo usaré para los ejercicios de todas las asignaturas del ciclo. De momento solo aparecen Programación y Lenguaje de Marcas, porque son las que me han proporcionado ejercicios hasta ahora. Iré añadiendo carpetas a medida que avance el curso.

## Estructura

- **Programacion/Java/**: ejercicios de Java ya ejecutados y comprobados.
- **Lenguaje-de-Marcas/HTML/**: prácticas de HTML.
- **Codigo sin ejecutar/**: ejercicios de Java que escribo desde el móvil en ratos libres del trabajo, cuando no tengo ordenador para ejecutarlos. Cada archivo lleva el marcador `//PENDIENTE DE EJECUTAR`. Cuando los ejecuto de verdad en el ordenador, compruebo la salida y que cumplan el enunciado, quito el marcador y los muevo a `Programacion/Java/`. Funciona como bandeja de entrada: si está vacía, es que no tengo nada pendiente de ejecutar.

## Origen de los ejercicios

- **Java:** ejercicios del libro *Aprende Java con ejercicios* (recurso del Moodle del curso).
- **HTML:** ejercicios proporcionados por el profesor de Lenguaje de Marcas.

## Cómo trabajo

**En casa o en clase (con ordenador):** escribo el código en el editor, lo compilo y lo ejecuto directamente, y compruebo yo mismo que la salida cumple el enunciado.

**En ratos libres del trabajo (solo con el móvil):** no puedo ejecutar nada, así que:

1. Escribo el ejercicio en las notas del móvil, con el enunciado como comentario al inicio.
2. Reviso el código antes de subirlo: sintaxis, lógica y cumplimiento del enunciado. En este caso uso una herramienta de IA solo para detectar errores y simular la ejecución; no me da la solución, corrijo yo.
3. Lo subo a `Codigo sin ejecutar/` con el marcador `//PENDIENTE DE EJECUTAR`, y cuando llego al ordenador lo ejecuto de verdad y comparo el resultado real con lo esperado.

## Nomenclatura de los archivos Java

Los archivos siguen el formato `LibroXEjercicioY.java`, donde **X** es el capítulo del libro y **Y** el número del ejercicio. Por ejemplo, `Libro2Ejercicio5.java` es el ejercicio 5 del capítulo 2.
